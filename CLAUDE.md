# mc-launcher — лаунчер Minecraft для macOS с ИИ-генератором сборок

Общие правила — в `../CLAUDE.md`.

## О проекте
Лаунчер Minecraft для Mac (Apple Silicon). Играть можно с офлайн-ником. Главные фишки:
1. Нативный запуск и оптимизация под Mac (ARM Java, профили JVM, Sodium/Lithium и т.п.).
2. ИИ-генератор модпаков: пользователь описывает сборку словами, ИИ подбирает моды.
3. Проверка совместимости модов: версия игры, загрузчик, зависимости, конфликты.

Сначала для себя и друзей, потом публичный релиз (тогда нужны подпись и нотаризация Apple, и юридическая проверка).
Рабочее название `mc-launcher`, имя продукта выберем позже.

## Особенности
- **Стек:** SwiftUI, Swift Package Manager. Xcode не стоит, есть только Command Line Tools, поэтому `.app` собираем скриптом из SwiftPM.
- **Позже Windows:** SwiftUI на Windows не переносится. Поэтому вся логика (скачивание, запуск, моды, ИИ) лежит в пакете `LauncherCore` и использует только Foundation, без AppKit/SwiftUI. Интерфейс отдельно, его потом можно заменить.
- **Игра:** файлы Mojang в проект не кладём, качаем с официальных серверов Mojang. Java тоже берём из манифеста Mojang (`mac-os-arm64`), системная Java не нужна.
- **Версии на старте:** Fabric, Minecraft 1.21.x и 1.20.1. Forge/NeoForge позже.
- **Моды:** источник Modrinth (открытый API, ключ не нужен). CurseForge позже.
- **ИИ:** свой ключ пользователя в настройках, Claude или Gemini на выбор. Ключ хранится в Keychain, в код и логи не попадает.
- **Аккаунты:** офлайн-ник (UUID из `OfflinePlayer:<ник>`). Вход через Microsoft можно добавить позже.
- **Этапы:** 1 ядро (скачать и запустить) → 2 моды и совместимость → 3 ИИ-генератор → 4 оптимизация под Mac.
