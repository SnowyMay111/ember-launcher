# Дизайн-спека «Voxel» (от владельца, 2026-10-26) + решения интервью

Делать СТРОГО по спеке, ничего не добавлять от себя: без цветов, эмодзи, лишних теней. «Voxel», «Nickname», названия сборок — заглушки. Если сомневаешься, лучше убрать, чем добавить.

## Решения интервью (важнее текста спеки, где противоречат)
- SwiftUI, macOS 14+, Swift 5 language mode. Веб-единицы px = pt 1:1. Тема (токены) в одном месте, без «магических» значений в экранах.
- Стекло своё (не `glassEffect`): размытие + градиент-заливка + рамка 1px + внутренний блик + тень, через NSVisualEffectView (blendingMode `.withinWindow`) под градиентом.
- Окно: скрытый заголовок, РОДНЫЕ кнопки светофора слева в верхней панели 56pt (свои цветные кружки не рисуем). Старт 1120×720, min 900×600. Фон окна чёрный, непрозрачный. Тёмная тема принудительно.
- Шрифты Geist 400/500/600 и Geist Mono 400/500 лежат в `Resources/Fonts` (PostScript-имена: Geist-Regular, Geist-Medium, Geist-SemiBold, GeistMono-Regular, GeistMono-Medium), регистрируются в коде локально.
- Данные: заглушки в коде (~8 сборок), структура модели под замену на хранилище.
- Живое: переключение экранов; чипы (All/Vanilla/Fabric/Forge) и поиск фильтруют список; настройки сохраняются в UserDefaults; клик по карточке в Library делает сборку текущей на экране Play. Кнопки Play / Instance settings / New instance / аккаунт пока без действия.
- Mods и Skins: заголовок страницы как на Settings (eyebrow «MODS», h1 «Mods», muted «Coming soon.»), то же свечение.
- Все тексты через функцию `L("English text")` (ключ = английский текст). Другие языки лежат в `Resources/Languages/<код>.json` и подхватываются сами. Иконки рисуем сами линиями (Shape), не SF Symbols.

## Стиль
Минимализм в духе conlee.pl: чистый чёрный фон, шрифт Geist, белые пилюли-кнопки, тонкие серые рамки и мягкое белое свечение. Поверх него полупрозрачные "liquid glass" поверхности. Строго монохром, акцентного цвета нет. Единственные цветные элементы — три точки macOS в левом верхнем углу окна (родные).

Макет окна: 1120×720.

- Заголовок страницы: 40, 600, -0.04em.
- Заголовок карточки: 17, 600. Значение в stat-карточке: 24, 600.
- Основной текст строки: 15, 500. Второстепенный: 13–16, цвет --muted.

- Не опускай серый ниже #8b8b8b.

## Стекло
Деликатное, читается только потому, что за ним мягкое белое свечение на чёрном.
.glass { fill: --glass-fill; blur 24 saturate 160%; border 1px rgba(255,255,255,.11); radius 18; shadow: inset 0 1px 0 rgba(255,255,255,.16), 0 20px 50px rgba(0,0,0,.5) }
Свечение — слои под контентом, не ловят клики (allowsHitTesting(false)):
- Play: круг 680 по центру за логотипом, radial-gradient(circle, rgba(255,255,255,.16), transparent 60%), плюс широкий слабый эллипс у нижнего края (rgba(255,255,255,.10), ≈920×420).
- Library и Settings: эллипс 840×600 над верхним краем (.14) и тот же слабый внизу (.09).
Верхняя панель: rgba(0,0,0,.55), blur 14, нижняя граница 1px #262626, высота 56.
