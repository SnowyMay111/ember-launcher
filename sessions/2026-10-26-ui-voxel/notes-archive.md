# Интерфейс «Voxel» по дизайн-спеке

**Задача:** собрать интерфейс лаунчера (Play, Library, Settings + заглушки Mods, Skins) строго по спеке владельца (чёрный фон, Geist, белые пилюли, своё «стекло», монохром).
**Статус:** интервью закончено, ждёт «го» на сборку.

## Решения владельца (интервью 2026-10-26)
- Стек: SwiftUI, всё нативно. Токены спеки — в одну тему (`Theme`), без инлайн-значений.
- Стекло: своё, строго по токенам (размытие + градиент + рамка 1px + внутренний блик), macOS 14+. Не родной Liquid Glass.
- Окно: скрытый заголовок, родные кнопки (красная/жёлтая/зелёная) слева в панели 56px. Старт 1120×720, можно менять, минимум 900×600. Скругление окна задаёт система.
- Шрифт: Geist 400/500/600 и Geist Mono 400/500 — скачать с github.com/vercel/geist-font (лицензия OFL), положить в проект, подключить локально. «Да» дано.
- Данные: заглушки в коде (~8 сборок, Survival и т.д.), структура под замену на реальное хранилище. Play пока ничего не запускает.
- Живое сейчас: переключение экранов; чипы и поиск фильтруют список; настройки сохраняются (UserDefaults); клик по карточке в Library делает её текущей на экране Play.
- Mods / Skins: тот же заголовок (eyebrow, h1) + серая строка «Coming soon.», свечение как на Settings.
- Язык: интерфейс на английском. Остальные языки (русский, украинский) лежат отдельными файлами в папке `Languages/`; удалил файл — язык пропал, код менять не надо; нет ключа или файла — английский. Язык берётся из системы (строки выбора языка в Settings в спеке нет, не добавляем).

## Мои решения (не спрашивал)
- Языковые файлы — JSON, загрузчик в `LauncherCore` (только Foundation, переиспользуется на Windows).
- Иконки рисуем сами линиями (куб, play, лупа), без SF Symbols.
- Для просмотра нужен скрипт сборки `.app` (пункт 4 из прошлых заметок), делаю заодно.
- Кириллицы в Geist нет → русский/украинский текст покажется системным шрифтом.
- Размытие внутри чёрного окна: `NSVisualEffectView` с режимом `withinWindow`, рабочий стол сквозь окно не просвечивает.
